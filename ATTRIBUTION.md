## Inspiration & Conceptual References
This project is an independently designed, modern open-source quadruped robotics platform built for ESP32 microcontrollers. 

Special thanks and acknowledgement to:

* **Dorian Todd (dorianborian)** - Creator of the [Sesame Robot](https://github.com/dorianborian/sesame-robot) project.
  * *Sesame Robot* served as a key conceptual reference for 8-DOF quadruped robot mechanics, joint layouts, and accessible DIY robotics design.
  * This project is an independent clean-room implementation written from scratch by Sayuru Gunathilaka and project contributors. It does not copy source code, binary assets, or user interface designs from the original Sesame Robot repository.
